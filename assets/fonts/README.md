# Card fonts

Bundled from the Google Fonts repository under the adjacent SIL Open Font Licenses:

- Space Grotesk: headings, names, statistics.
- IBM Plex Mono Medium: metadata and labels.
- Kalam Regular: handwritten doodle captions.

The renderer embeds these font files in the executable and caches its font database.
System fonts provide fallback coverage for other scripts. The VPS installs Noto Core.

Sources: https://github.com/google/fonts/tree/main/ofl/spacegrotesk,
https://github.com/google/fonts/tree/main/ofl/ibmplexmono,
https://github.com/google/fonts/tree/main/ofl/kalam.
